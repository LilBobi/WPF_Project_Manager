# Project Manager (Менеджер проектов)

Десктопное приложение для управления проектами на C# (WPF).
Программа позволяет добавлять задачи, назначать исполнителей и отслеживать статус выполнения.
Взаимодействует с реляционной базой данных MS SQL Server через Entity Framework.
База данных разворачивается локально с помощью Docker, что обеспечивает быстрый старт проекта без необходимости установки тяжелого SQL-сервера на компьютер.

## Требования к системе
* **Windows 10/11** с включенной подсистемой WSL.
* **Visual Studio** (рекомендуется 2022) с рабочей нагрузкой "Разработка классических приложений .NET".
* **Docker Desktop** для запуска контейнера базы данных.

## Инструкция по запуску

1. **Скачивание проекта**
   Откройте терминал и клонируйте репозиторий:
   `git clone https://github.com/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git`

2. **Запуск сервера базы данных**
   Убедитесь, что программа Docker Desktop запущена. Откройте терминал в папке скачанного проекта и выполните команду:
   `docker-compose up -d`
   *(Это скачает и запустит чистый локальный SQL-сервер в фоновом режиме).*

3. **Создание структуры таблиц**
   Откройте проект в Visual Studio. 
   В панели "Обозреватель решений" (Solution Explorer) найдите файл `BD_Proect_Meneger.sql` и откройте его. 
   Нажмите кнопку **Выполнить** (зеленый треугольник в левом верхнем углу окна кода) и введите данные для подключения:
   * **Имя сервера:** `localhost,1433`
   * **Проверка подлинности:** Проверка подлинности SQL Server
   * **Имя пользователя:** `sa`
   * **Пароль:** `Qwerty123!`
   * В параметрах обязательно поставьте галочку **Доверять сертификату сервера** (Trust server certificate) и нажмите "Подключиться".
   Скрипт выполнится, и база данных будет создана.

4. **Запуск программы**
   Откройте решение `Project_Menedger.sln` в Visual Studio и нажмите `F5`, чтобы запустить приложение. Программа автоматически подключится к готовой базе.
